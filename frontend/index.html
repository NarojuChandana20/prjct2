Pipeline Architecture

• Branch 1 (Body): YOLO11 Person Tracker → MediaPipe Pose Landmarker → 165 Features → BiLSTM Sequence Classifier.

• Branch 2 (Emotion): MediaPipe Face Detector → EfficientNetB0 (7 RAF-DB classes).

• Branch 3 (Spatial Match): Head-zone geometric association (top 40% person bbox) with 1-to-1 matching and ambiguity rejection.
